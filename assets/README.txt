Logo override
=============

Drop your Lotus's logo image in THIS folder to replace the built-in text/SVG
logo everywhere in the app (sidebar + login screens).

Accepted file name (any one of):
    lotus_logo.png   (recommended)
    lotus_logo.svg
    lotus_logo.jpg / .jpeg / .webp / .gif
    logo.png  /  lotuss_logo.png   (also accepted)

Notes:
- A raster file (.png/.jpg/.webp) is preferred over .svg if both exist.
- Transparent-background PNG looks best on the dark sidebar.
- No code change or restart of the file is needed — just add the image and
  reload the app (the logo is read fresh on each page render).
- Remove the file to go back to the built-in SVG logo automatically.

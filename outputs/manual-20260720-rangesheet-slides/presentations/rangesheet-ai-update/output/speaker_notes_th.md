# Speaker Notes: AI In Development

ช่วงแรกของโปรเจกต์นี้ต้องยอมรับว่า ด้วยระยะเวลาที่มีจำกัด ถ้าเขียนทุกอย่างด้วยมือทั้งหมด อาจทำได้ไม่เต็มที่ เพราะระบบไม่ได้เป็นแค่หน้าเว็บทั่วไป แต่ต้องทำงานกับข้อมูลจริงที่มีจำนวนมาก และมี logic ทางธุรกิจเข้ามาเกี่ยวข้องหลายส่วน

งานจริงมีความซับซ้อนมากกว่าสิ่งที่เรียนมาโดยตรง เช่น การเชื่อม filter, การแก้ dropdown แล้วต้องส่งผลต่อ status, cluster table, range architecture, report, autosave, audit log และ export file พร้อมกัน ทำให้ระหว่างทำเจอปัญหาที่ไม่ได้คาดไว้ เช่น โหลดช้า, state ไม่ค้าง, ตารางนับไม่ตรง, หรือข้อมูล column ไม่เหมือนกันในแต่ละไฟล์

AI เข้ามาช่วยในฐานะผู้ช่วยพัฒนา ช่วยเสนอแนวทางเขียนโค้ด debug error อธิบายสาเหตุของปัญหา และช่วยคิดวิธี optimize ให้แอพทำงานเร็วขึ้น แต่การตัดสินใจสุดท้ายยังต้องอิงจาก business logic และผลลัพธ์ที่ผู้ใช้ต้องการจริง

สิ่งที่ได้เรียนรู้คือ การทำ web app จากข้อมูลจริงไม่ใช่แค่เขียนโค้ดให้รันได้ แต่ต้องเข้าใจ flow ของข้อมูล เข้าใจว่าการแก้ไขหนึ่งจุดส่งผลต่อส่วนอื่นอย่างไร และต้องออกแบบให้ผู้ใช้ทำงานต่อได้จริง แม้ระบบจะมีความซับซ้อนมากขึ้น

สรุปคือ AI ช่วยให้เรียนรู้และพัฒนาได้เร็วขึ้น โดยเฉพาะในส่วนที่นอกเหนือจากที่เรียนมา เช่น debugging, performance, state management และการเชื่อม logic หลายตารางเข้าด้วยกัน แต่ความถูกต้องของระบบยังต้องมาจากการตรวจสอบกับข้อมูลจริงและ requirement ทางธุรกิจ

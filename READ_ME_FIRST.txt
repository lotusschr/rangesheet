===============================================================
  RangeSheet - วิธีเริ่มใช้งาน
===============================================================

  อ่านแค่หน้านี้พอครับ ไม่ต้องลงโปรแกรมอะไรเพิ่ม


---------------------------------------------------------------
  ต้องมีอะไรบ้าง
---------------------------------------------------------------

  - คอมพิวเตอร์ Windows
  - อินเทอร์เน็ต (เฉพาะครั้งแรกที่เปิดเท่านั้น)

  ไม่ต้องลง Python
  ไม่ต้องลง Git
  ไม่ต้องขอสิทธิ์ admin


---------------------------------------------------------------
  วิธีเปิดโปรแกรม
---------------------------------------------------------------

  1. แตกไฟล์ ZIP ออกมาก่อน

     สำคัญ: ต้องแตกไฟล์ออกมาจริง ๆ ก่อน
     ห้ามดับเบิลคลิกเข้าไปดูใน ZIP แล้วกดรันจากข้างใน มันจะไม่ทำงาน

     คลิกขวาที่ไฟล์ ZIP -> Extract All... -> Extract


  2. เข้าไปในโฟลเดอร์ที่แตกออกมา


  3. ดับเบิลคลิกไฟล์ชื่อ

         START_RANGESHEET.bat

     จะมีหน้าต่างสีดำเด้งขึ้นมา ปล่อยมันไว้ อย่าเพิ่งปิด


  4. รอจนเบราว์เซอร์เปิดขึ้นมาเอง แล้วใช้งานได้เลย

     ครั้งแรก: รอ 5-15 นาที (โปรแกรมกำลังโหลดของที่ต้องใช้)
     ครั้งต่อไป: เปิดใน 10 วินาที


---------------------------------------------------------------
  วิธีปิดโปรแกรม
---------------------------------------------------------------

  ปิดหน้าต่างสีดำทิ้ง เป็นอันจบ


---------------------------------------------------------------
  ถ้าเบราว์เซอร์ไม่เปิดขึ้นมาเอง
---------------------------------------------------------------

  เปิด Chrome หรือ Edge แล้วพิมพ์ที่ช่อง address:

         http://localhost:8501


---------------------------------------------------------------
  ถ้ามีปัญหา
---------------------------------------------------------------

  ขึ้นว่า "ไม่พบไฟล์ APP.py"
    -> ยังไม่ได้แตกไฟล์ ZIP ออกมา หรือกดรันจากในไฟล์ ZIP
       ให้แตกไฟล์ออกมาก่อน แล้วเข้าไปในโฟลเดอร์ที่แตกออกมา

  ขึ้นว่า "ดาวน์โหลด Python ไม่สำเร็จ"
    -> เน็ตบริษัทบล็อกเว็บ python.org อยู่
       ลองต่อเน็ตมือถือ (hotspot) แล้วเปิดใหม่อีกครั้ง
       ทำครั้งเดียวพอ ครั้งต่อไปไม่ต้องต่อเน็ตแล้ว

  ขึ้นว่า "ติดตั้งไลบรารีไม่สำเร็จ"
    -> ส่วนใหญ่เกิดจากเน็ตหลุดกลางทาง
       ดับเบิลคลิก START_RANGESHEET.bat ใหม่อีกครั้งได้เลย
       ไม่ต้องลบอะไร มันจะทำต่อจากเดิม

  Windows ขึ้นเตือนว่าไฟล์อาจไม่ปลอดภัย
    -> กด "More info" แล้วกด "Run anyway"
       (เกิดกับไฟล์ที่โหลดมาจากอินเทอร์เน็ตทุกไฟล์)

  แก้ไม่ได้จริง ๆ
    -> ถ่ายรูปหน้าจอสีดำทั้งหน้า ส่งให้ทีมพัฒนา


---------------------------------------------------------------
  อยากลบโปรแกรมทิ้ง
---------------------------------------------------------------

  ลบโฟลเดอร์นี้ทิ้งทั้งโฟลเดอร์ จบ

  โปรแกรมไม่ได้ติดตั้งอะไรลงเครื่องเลย ทุกอย่างอยู่ในโฟลเดอร์นี้
  ไม่มีอะไรค้างใน Windows
